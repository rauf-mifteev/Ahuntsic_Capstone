# Définition de « prêt »

Les conditions pour qu'un récit puisse entrer dans un sprint.

Un récit peut entrer dans un sprint quand :

- les trois membres comprennent ce qu'il faut faire ;
- il a des critères d'acceptation qu'on peut vérifier par oui ou non ;
- il est estimé en points ;
- les maquettes ou le contrat d'API dont il a besoin existent.

Si un récit ne remplit pas ces conditions, on ne l'engage pas. On le laisse dans le carnet et on le prépare pour le sprint suivant.
