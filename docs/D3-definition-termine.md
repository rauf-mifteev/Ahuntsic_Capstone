# Définition de « terminé »

Un récit est terminé quand :

- le code est fusionné dans la branche principale après relecture par un autre membre ;
- les tests automatisés passent et couvrent ce qui a été ajouté ;
- la fonctionnalité est déployée en ligne et vérifiée là-bas ;
- la documentation touchée est à jour ;
- les critères d'acceptation du récit sont tous remplis.

Ce qui marche seulement sur nos ordinateurs n'est pas terminé.

Statuts dans Jira

On utilise trois statuts, et rien d'autre.

To Do : le récit est engagé dans le sprint, personne n'a commencé.
In Progress : quelqu'un travaille dessus. Une seule personne à la fois par récit.
Done : les cinq conditions ci-dessus sont remplies.

On passe un récit à Done dès qu'il est terminé, sans attendre la revue. Si le client refuse quelque chose à la revue, on crée une nouvelle tâche pour la correction au lieu de rouvrir l'ancienne. Ça garde l'historique du sprint clair.
