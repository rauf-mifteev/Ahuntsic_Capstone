# Contrat d'équipe

Rôles

Rauf Mifteev : backend, API, base de données. Il anime aussi les rituels.
Daniel Alain Dyky : déploiement, intégration continue, circuit simulé, modèle, documentation technique.
Chahrazad Tayibi : application mobile, maquettes, design.

Le modèle est partagé : les trois prennent des photos, Daniel l'entraîne, Rauf le met en service, Chahrazad l'intègre dans l'application.

Quand on travaille

Ensemble pendant les heures de cours. C'est là qu'on fait les rituels, qu'on décide et qu'on règle les blocages.

Chacun de son côté le reste du temps, selon ses disponibilités.

Comment on décide

On discute jusqu'à ce que les trois soient d'accord. Si on n'y arrive pas, on vote. Les décisions importantes sont notées dans `docs/`.

Si le désaccord porte sur le périmètre, on l'apporte au client.

Si quelqu'un est bloqué

Il le dit sur Teams tout de suite, sans attendre le prochain cours. Une personne bloquée qui attend, c'est une journée perdue.

Si quelqu'un est absent

Il prévient dès qu'il le sait. On redistribue son travail au cours suivant.

Partage des connaissances

Chacun présente sa partie aux deux autres quand il la met en place. Personne ne doit être le seul à comprendre une partie du système.
